# Gambar layar dari Figma

Taruh hasil export PNG di folder ini. Claude membaca gambar ini untuk membangun setiap layar.

## Cara export (gratis, tanpa plugin)

1. Buka file Figma **catat.** → halaman **Prototoype - Catat.**
2. Pilih semua frame layar **00–26**. Cara cepat: klik frame pertama, tahan **Shift**, lalu klik yang lain.
3. Di panel kanan **Export**, klik **+**, lalu pilih **2x** dan **PNG**.
4. Klik **Export N layers** dan pilih folder ini (`design/screens/`).

Figma memberi nama file sesuai nama frame, misalnya `03 · Beranda.png`. Nama seperti itu tidak masalah dan tidak perlu diganti.
Setiap kali desain di Figma berubah, export ulang layar yang berubah ke folder ini.
